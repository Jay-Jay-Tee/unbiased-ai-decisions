# Contributing to Unveil

Thank you for your interest in contributing to **Unveil** 🚀

Unveil is an AI-powered fairness, bias detection, and explainability platform focused on identifying hidden risks in machine learning systems through:
- bias analysis
- slice evaluation
- SHAP explainability
- counterfactual analysis
- proxy detection
- fairness reporting

We welcome improvements, bug fixes, optimizations, and new ideas.

---

# 📌 Project Philosophy

This project prioritizes:
- transparency
- responsible AI development
- reproducibility
- explainability
- fairness-aware machine learning

Contributions should align with these principles.

---

# 🚀 Getting Started

## 1. Fork the Repository

```bash
git clone https://github.com/Jay-Jay-Tee/unveil.git
cd unveil
```

---

## 2. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

Examples:
- `feature/shap-improvements`
- `fix/proxy-detection-bug`
- `docs/readme-update`
- `optimization/pipeline-speedup`

---

# 🛠 Development Setup

Install backend dependencies:

```bash
pip install -r docs/requirements.txt
```

Install frontend dependencies:

```bash
npm install
```

Run the development environment as described in:

```txt
docs/HOW_TO_RUN.md
```

# 🧠 Coding Guidelines

## Python
- Follow PEP8 standards
- Use meaningful variable names
- Keep functions modular
- Add docstrings where useful
- Avoid unnecessary complexity

## Frontend
- Maintain readable component structure
- Keep UI accessible and responsive
- Avoid excessive dependencies

---

# 🔬 ML & Fairness Guidelines

When contributing ML-related features:

- explain assumptions clearly
- document datasets used
- avoid introducing biased heuristics
- maintain reproducibility
- validate outputs carefully

Fairness-related contributions should include:
- methodology explanation
- reasoning behind metrics
- limitations and edge cases

---

# 🐞 Reporting Issues

Please include:
- clear description
- expected behavior
- actual behavior
- reproduction steps
- logs/screenshots if relevant

---

# 🔀 Pull Request Process

1. Fork the repository
2. Create your branch
3. Commit changes

```bash
git commit -m "Add: improved SHAP visualization pipeline"
```

4. Push changes

```bash
git push origin feature/your-feature-name
```

5. Open a Pull Request

---

# ✅ Pull Request Checklist

Before submitting:

- [ ] Code runs successfully
- [ ] No breaking changes introduced
- [ ] Documentation updated if necessary
- [ ] Fairness/ML logic explained clearly
- [ ] No sensitive data or secrets committed

---

# 🔒 Sensitive Data Policy

Do NOT commit:
- API keys
- Gemini credentials
- Firebase secrets
- private datasets
- `.env` files

Use:
- `.env.example`
- environment variables
- local configuration files
